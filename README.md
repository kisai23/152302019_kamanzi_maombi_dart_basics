## How to Run the Programs

Make sure Dart SDK is installed on your computer.

Open PowerShell in the project folder and execute:

**1. Run Dart Basics:**

```powershell
dart run dart_basics.dart
```

**2. Run MoMo Simulator:**

```powershell
dart run momo_sim.dart
```
